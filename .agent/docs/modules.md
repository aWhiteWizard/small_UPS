## 1. 本体模块清单

### 1.1 输入与 EMI/保护（M1）

> 责任边界：220VAC 入口至整流桥输出（HV_BUS）。M1 负责 EMI 滤波、浪涌抑制、输入保护、安规间距与整流；不负责稳压、隔离与输出调压（PFC/LLC/buck/辅助见 §1.2–§1.5）。来源：`.agent/module-design.md` M1（选型 M1-1…M1-9、参数计算、布局、失效）；本单不改 M1 参数。

> 链路（R §3.5.4 + architecture §2.1）：IEC C14 入口 → 急停 P-15（机械 L/N 切断，串接位置待结构确认）→ T2A/250V 延时保险丝（L）→ 双极船型开关 10A/250V（L/N 同断）→ NTC 5D-15 → MOV 14D561K → X2 0.47µF/275VAC + 1MΩ 泄放 → 共模电感 10mH/2A → Y 2×2.2nF/250VAC（单点 PE）→ 整流桥 800V/8A（贴 CNC 散热器）→ HV_BUS。

**布局要点（M1 结论 3 条）**

- 强电集中进线侧（Z0）：保险丝/开关/NTC/MOV/X2 一字排布，X2/CM 靠近入口；开槽 8mm/6mm，220V—SELV/PE 爬电 ≥8mm、间隙 ≥6mm；CM/变压器下方禁走弱电信号（architecture §12.2/§13.4）。

- 高频环路 ≤1.5cm²：输入陶瓷/上管/下管/功率地回路最小。
- SW 节点铜皮小：降低 dv/dt 辐射与对采样/驱动回路的耦合。
- 采样开尔文差分：2mΩ 两端独立差分走线，避开 SW/栅极。
- 栅极 ≤1.5cm：buck 2 路栅极回路短、独立。
- 功率地/信号地单点在输出电容负极汇合，不形成多点接地。
- 补充：输入高频陶瓷紧贴上管（architecture §13.4）；电感屏蔽，输出滤波/ORing 就近（R §3.5.8/architecture §13.4）；不改 M4 参数。

**RS 锁存、CLEAR 双条件与门、ALERT 开漏线与、EN 门**

- **74HC74 锁存**：5 片 74HC74（10 个 D-FF，用 9 个），3.3V 辅助域；异步 `/SET` 置位、异步 `/R` 复位，Q 高=故障锁存。各比较器/单稳输出经故障二极管或到 SET；Q 直接参与 5 路使能门、继电器线圈低边与 ALERT，不经过 MCU。上电 10k/100nF + 施密特产生复位脉冲，冷启动 Q=0；MCU NRST 只清 READ_DONE，不清 Q；辅助掉电按整机掉电处理，上电后源仍在会重新置位。
- **CLEAR 双条件与门**：`SOURCE_GONE & READ_DONE` 两条件同时成立才允许复位。READ_DONE 由“读 0x08（FAULT_CODE）”与“读 0x09–0x0C（FAULT_FLAGS）”两个读选通共同置位；只读其一不置位。写 0x0D=0xA5 产生 1µs 选通脉冲触发复位；新故障 `FAULT_ANY` 否决 CLEAR（SET 优先）。CLEAR 同时清软使能，输出保持 OFF，必须重新走完整使能序列；不允许上电/看门狗复位自动 CLEAR。architecture §14.3.2 用四输入门实现（READ_DONE、SOURCE_GONE、CLEAR_STROBE、`!FAULT_ANY`），其中选通与“新故障否决”是命令/优先级，不改变 M7 的“源消失 + 已读码”双条件语义；口径见待确认 #2。
- **ALERT 开漏线与**：全部硬件 Q（本单六类 + architecture §14.4 的 HB/SHORT/REVERSE_INSERT 等，9 个 Q）+ OVP/OCP/SCP/反灌 4 个快速原始跳变 + MCU 软件故障 ALERT_DRV，经 74HC32 或门树驱动 BSS138 栅极；漏极即 ALERT（A25）。低有效开漏，本体仅 100Ω 串联 + ESD、不加上拉；调试板 10k 上拉到 3.3V；任一机拉低即低（wired-OR），最大灌电流 10mA、耐压 ≥30V、ESD ≥±8kV 接触；未上电/故障机高阻，不反向供电。ALERT 只通知，不替代保护；硬件保护链独立完成关断。M7 要求接 MCU 中断并引到金手指，R §2.3.1 定电气。
- **EN 硬件门**：B25 EN 高有效，100Ω + 10k 下拉 + 74AHC1G17 施密特；EN 直接进驱动使能门，不经 MCU。门方程 `DRV_EN = EN & SHORT_OK & !FAULT_OR & SOFT_EN`（architecture §14.2/§14.4）；EN 低立即关门（≤1ms），低持续 20ms 去抖后锁存 EN_LOST（0x0A）；EN 高需稳定 10–50ms 才参与使能。MCU 复位/死机时 SOFT_EN=0，门关；软件不能越过 EN/SHORT/FAULT。

**12V 与短针回路（D1 结论）**

- A22 为本体 12V 输出（12V±5%，1A 连续/1.5A 10s），入 D 板经 PTC 1.5A + TVS SMBJ15A 后形成 12V 轨；板内 5V/3.3V、PT100 +12V、面板/通信由此分配。
- B22 为 D 板回送本体的 12V：12V 轨 → B22 回路 PTC（沿用现有值/位置，D1 未给新值）→ B22 → 本体继电器线圈 → A23/B23 短针 → D 板 12V 回流铜皮 → A21/B21 → 本体 SGND 星点。短针不在位，线圈回路断开，继电器不能吸合、输出不能使能。
- 拔出时短针最先断开（L=8.0±0.1mm，s=2.0±0.1mm），继电器硬件释放 ≤50ms，不依赖 MCU；本体检测 B22 <10V、≤20ms 去抖置 SHORT_PIN_LOST 0x09；OUT_ON=1 时同时置非易失拔出锁存；恢复/重插/上电均不得自动重合，必须人工 CLEAR + 重新使能。
- 正常更换：先 I2C 关输出 → OUT_ON=0、RELAY_STATE=0、VOUT_ZERO=1、无锁存故障 → 解锁 → 再拔；不允许带电插拔（R §2.1.4）。
- 12V 外设回流只走 A21/B21（继电器线圈回路另经 A23/B23；每针 ≤0.5A 连续、≤0.75A 峰值），不借用 B22；12V 与 3.3V/5V/信号分区，12V 回流铜皮不穿信号/采样地。

**关断熄灭与 12V 待机功耗（D2）**

- D2 电流口径为全亮峰值 320mA、平均 40mA（1/8 扫描）；按 3.3V 显示域折算，显示平均功率约 0.13W，计入 595/位驱动与 5V buck/3.3V LDO 损耗后对 12V 输入的加载 ≤0.3W（0.3W 上限折合约 25mA@12V）。0.3W 取 D2 的节省上限口径，精确值首样实测。
- 输出关断时，D2 要求固件装入熄灭帧并关断段/位驱动（不只写 0），显示支路电流降到接近 0，最多可从 12V 辅助负载中释放 0.3W；若熄灭失效，12V 待机负载最多多背 0.3W。故障态仍按 R §4.2.2 归零显示，是否同样熄灭见待确认 #1。
- R §3.5.11/附录 N.6 的待机 <1.5W 口径是“本体空载、PFC 停振、12V 不带载、不含调试板”；本项 ≤0.3W 是 D 板接上后显示支路对 12V 辅助的占用，不改变该验收口径，但占用 A22 1A 连续预算的一小部分，关断熄灭后释放。
- 12V 辅助在输出 OFF 时仍工作（R P-14），显示/按键/I2C 可用；熄灭策略只关显示，不关 MCU/按键扫描/I2C，避免待机时无法用电源键重新开启；熄灭帧不得清故障锁存。

**掉线/超温对本体输出的影响与恢复条件（D3）**

- 采样与判定：500ms/次读 1 个寄存器；超时/CRC 错/非法应答/读数越界/开路/短路均计失败；连续 3 个采样周期（≥1.5s）失败 → 温度无效；读数陈旧 >1.5s 按无效，不得当“温度正常”。
- 掉线对本体输出：立即拉低 EN + I2C 写 `OUTPUT_ENABLE=0`，本体硬件关门/继电器释放；`PT100_LOST` 本地锁存；温度无效期间**禁止开启输出**，已开启强制关断；本体后面板故障灯亮/闪、PC 工具可读（R §4.2.5；D 本地锁存不进本体 `FAULT_CODE`，可见性路径见待确认 #6），不自动恢复。
- 超温对本体输出：温度 ≥阈值 → 立即强制关断并锁存 `OT`；≤阈值−2.0°C 才允许重新使能；新阈值 ≤当前温度立即按超温处理；同样不显示温度/文字，不替代本体 OTP（NTC ≥95°C 的 0x05 独立生效）。
- 恢复条件：连续 3 次有效读数解除“温度无效”；输出仍需人工重新使能（不得因读数恢复、解锁或重新上电自动重合闸）；`PT100_LOST`/`OT` 本地锁存的清除入口在 R/architecture 未明确，按待确认 #5 处理。
- D 掉电/复位/拔插：EN 下拉 → 本体输出 OFF；恢复供电/I2C 重连后先确认 PT100 有效，再走人工重新使能；不得复位即 EN 高。
