## 1. 产品组成
- 电源本体（金手指模块，P 类）+ 电源调试板（D 类）。不含上位机软件。

### 1.1 电源本体
- P-01 前面板：单排 64 针 2.54mm 金手指；后面板：220V 三孔输入、免开盖可换保险丝、4 位拨码（I2C 地址）。
- P-02 输出 0–48V / 最大 5A，I2C 设定，步进 0.1V / 0.01A。
- P-03 不允许带电插拔：短针保持回路 + 输出隔离。
- P-04 I2C 地址 = 0x30 + 拨码（0x30–0x3F）；不实现广播。
- P-05 输出电流/电压采样。
- P-06 保护：过压、欠压、过流、短路、过温、反接。
- P-07 辅助电源（standby）：220V 上电即工作，输出 12V 经金手指供调试板；不受输出继电器控制。

### 1.2 电源调试板
- D-01 64 针卡边插槽；外轮廓与本体一致（宽 120），带 Ø5 圆孔与 Ø8 腰形孔对应定位销；插到底后前面板齐平。
- D-02 数码管两页：第 1 页电压+电流；第 2 页 PT100 温度。
- D-03 5 键：屏下方 左/右/SET，屏侧边 上/下。
- D-04 SET 流程：设输出电压 → 再设最大电流 → 再 SET 确认；左右选位，上下改数。
- D-05 温度页设阈值（两级保护）。
- D-06 PT100 一路、香蕉头一对、电源按钮（控输出）。
- D-07 由本体 12V 供电（经金手指），经短针把 12V 回送本体继电器。

## 2. 机械
- 本体：120（宽）× 50（高）× 180（深）mm，卧式铝壳，自然散热。
- 内部净深约 125–135mm（扣除插深与后板元件），故必须自绘 AC/DC，不用成品开放框模块；电容高度 ≤25mm；MOS/变压器贴壳导热。
- 约束：散热面积约 0.13 m²，效率需 ≥92% 才能靠自然散热，否则需底面加鳍片（外观高度将超 50）。
- 定位销：装在前壳，Ø5（距左 10mm）、Ø8（距右 20mm），长度大于金手指接触长度，与电路绝缘。
- 调试板：外形与本体一致，对应孔位一个圆孔一个腰形孔。

## 3. 连接器与针脚（64 针 = A 面 32 + B 面 32）
| 针位 | A 面 | B 面 |
|---|---|---|
| 1–10 | 输出+ | 输出+ |
| 11–20 | 输出− | 输出− |
| 21 | 信号地 | 信号地 |
| 22 | +12V（本体→调试板） | +12V（调试板→本体继电器，经短针） |
| 23 | 短针 SHORT | 短针 SHORT（冗余） |
| 24 | SDA | SCL |
| 25 | ALERT | ID（备用） |
| 26–32 | GND 护边 | GND 护边 |

- 不做防呆键位；代偿：外侧 GND 护边、电源/信号分区、调试板插反检测（信号针 >16V 立即断路报警）、丝印方向标识。
- 金手指 PCB 工艺：1.6mm 板厚、倒角 30°、硬金 ≥1µm；短针铜箔缩短 3–5mm。
- 12V 路径两端各串自恢复保险（PTC）。

## 4. 保护策略
- 过流/短路：硬件比较器 µs 级关断 MOS（主保护）+ 继电器物理隔离（fail-open，不自动重合闸）；关断后泄放回路 100ms 内降到安全电压。
- PT100 超温两级：一级切输出（保留风扇与显示、I2C 置故障）；二级继续升高则切整机 220V。
- 220V 急停：红色自锁蘑菇头，机械串接（建议火零双断），不经软件，人工复位，状态反馈 MCU。

## 5. 指标（验收「合格」，目标「良好」）
| 指标 | 合格 | 良好 | 备注/测法 |
|---|---|---|---|
| 显示精度 | ±0.5% FS | ±(0.1%读数+0.05%FS) | 6 位半表比对 |
| 纹波（满载 20MHz BW） | ≤100 mVpp | ≤50 mVpp | 弹簧地环，满载/半载/空载 |
| 效率（满载/半载） | ≥87% / ≥85% | ≥92% / ≥90% | 功率计+电子负载 |
| 空载功耗（本体，不含调试板） | <1 W | <0.5 W | 220V 通电、输出关断、不接调试板 |
| 输出建立 / 设定响应 | ≤100ms / ≤100ms | ≤50ms / ≤30ms | 示波器 |
| 插入到 I2C 可通信 | ≤500ms | ≤200ms | 逻辑分析仪 |
| 过流/短路响应 | ≤10µs | 同左 | 硬件比较器 |
| 负载调整率 / 温度系数 | ≤0.5% / ≤100ppm | ≤0.1% / ≤50ppm | 负载阶跃/高低温 |
| PT100 精度 | ±1℃ | ±0.5℃ | 冰水沸水两点 |
