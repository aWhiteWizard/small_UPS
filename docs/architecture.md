## 1. 系统框图

### 1.1 整机框图（T-0007）

```text
220VAC → 保险丝/双极开关 → EMI 滤波 → PFC(400V) → LLC 隔离(55V) → 同步 buck(0.5–48V) → 滤波/继电器 → 金手指 → 调试板/负载
                                      │                    │
                                      └─ 辅助 12V ─────────┴─ MCU/采样/保护/I2C/EN/ALERT
调试板：STM32 + 显示/按键 + PT100(Modbus) + USB-UART 升级 → I2C/EN/ALERT/12V 金手指
```

> 说明：本图只定系统边界与能量流；各段器件/拓扑由 T-0011 展开，时序见 §5。

### 1.2 板卡与外部系统边界

- 电源本体：220VAC 输入；前壳 60×120 接插面，金手指竖条偏左、Ø5/Ø8 定位销前伸 15–18mm；经 64 针输出 0–48V/5A、辅助 12V、I2C/EN/ALERT/UART。
- 电源调试板：前面板 60×120×35 竖立式；背面承插腔接收本体金手指/定位销，正面 8 位数码管 + 5 键 + 独立电源键；外部 USB-C（数据 only）、RS485/PT100 供电端子、Ø4 香蕉头（0–48V/5A）；内部 3.3V/5V/12V。
- 边界原则：功率只经金手指 1–20 针；12V 只经 A22/B22 + 短针；USB-C/RS485 为信号/辅助接口，不承载 220V；调试板不改变本体保护/使能链，EN 硬件门与继电器仍由本体执行。

## 5. 时序总览

| 时序项 | 触发 | 关键节点 | 需求引用 | 填充单 |
|---|---|---|---|---|
| 上电/自检 | AC 上电/复位 | 辅助电源 → 自检 → PFC 400V → LLC 55V → READY；任一步失败锁存并禁输出 | R §2.4.1 | T-0006 |
| 掉电/欠压 | AC<180/150VAC、PFC<320V、55V<50V | 禁 buck → 释放继电器 → 泄放；POWER_LOST/PFC_FAULT/UNDERVOLTAGE(0x04)；恢复不自动输出 | R §2.4.1、§3.3.3 | T-0006 |
| 输出使能/关断 | EN/软使能/短针/心跳 | 四条件与门 + 心跳/校准/COMMIT 前置 → 继电器（≤50ms）→ 软启动；关断 100ms 内 ≤1V | R §2.4.2、§3.1 P-04 | T-0006/T-0009 |
| 故障锁存/ALERT | 硬件比较器/软件检测 | ≤10µs（硬件）/≤1ms（软件）关断+锁存；读码+CLEAR+重新使能；不自动重试 | R §2.3.5、§3.3.5 | T-0006 |
| 插拔/短针 | 短针丢失/插反 | 立即释放继电器；SHORT_PIN_LOST/REVERSE_INSERT；禁止带电插拔 | R §2.1.4 | T-0006 |
| 固件升级 | 升级请求/CRC 失败 | EN 低、停 PFC/LLC；bootloader 等重传；无版本门禁 | R §2.4.3、§3.3.6 | T-0006 |
